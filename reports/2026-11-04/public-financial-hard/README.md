# 公开金融材料难度升级小试：多页核查与完整差异枚举

日期：2026-11-04。本轮目标是逐步提高题目难度，并实际检验Luna能否完成。所有原件来自公开来源，未使用原先敏感材料。修改件是研究构造，不代表官方发布内容。

上一轮[基础10题](../public-financial-pilot/README.md)的临时内容完成分为95/100。本轮保留同一模型、medium effort、1800像素长边和一次盲答的方式，增加跨页关系、修改完整性、单位与年度理解，以及正常对照的复杂度。没有通过降低图片分辨率、裁去必要证据或超过输出容量来制造难度。

## 2. 逐步增加了哪些难度

### 第一步：单页自洽，跨页出现矛盾

H01把2025年资产负债表中的现金从1,187.7改为1,188.4，同时把贷款应收从2,002.5改为2,001.8。两项变动分别为+0.7和-0.7，资产合计保持6,055.4。另一页现金流量表仍列示期末现金1,187.7，且其期初现金1,177.7加当期变动10.0也得到1,187.7。只有把同年度、同单位、同指标匹配起来，才能验证这条跨页矛盾。

H02进一步同步修改运营表中的10个单元格，使本页几条主要关系继续成立。例如：

```text
其他基金净成本：4,592.0 + 112.8 = 4,704.8
净成本总额：4,704.8 + 2,752.8 - 112.8 = 7,344.8
净运营结果：5,244.6 - 7,344.8 = -2,100.2
期末净资产：-39,649.3 + 19.1 - 2,100.2 = -41,730.4
```

但净成本表仍是7,337.8，调节表的净运营成本仍是2,093.2，资产负债表的期末净资产仍是-41,723.4。已核验这些列明的局部关系，没有据此认证全文所有会计关系。

### 第二步：从发现一处变化，升级到找全多处变化

H03要求在两套各4页的报表中找全上述10处修改，包括相同金额在不同位置的重复出现。H04在3页上置换9个单元格，出现的数字集合保持不变，但数字所属的科目、列或页面位置改变。H07跨两页修改7处，包含负号消失、末位小数变化和重复金额同步修改。

各题都要求逐个单元格或标签位置列出，不把“有一组数交换了”算成找全所有变化。评分同时记录召回和额外误报，不用一句正确的概括代替字段证据。

### 第三步：金额数字不变，单位或年度标签改变

H09只把资产负债表单位从 **billions** 改为 **millions**，所有金额数字保持不变。页内加总仍成立，但与现金流量表和运营表中同年度重复指标的金额尺度相差1000倍。

H10则在3页中同步修改单位及2025年度标签，共11处，金额数字完全不变。它采用双版本对比，要求检查标题和单位，而不只是扫描数字区域。页眉、表题及列标题属于不同位置，按题面约定分别计数。

### 正常对照：合法差异不应被当成篡改

H05给出未修改的4页报表。H06给出两份官方报告：2024年原报总资产5,662.1，与下一年报告中明确标为Restated的2024年总资产5,683.8不同，但本实验没有编辑它们。H08只改变页面顺序并做正常JPEG重编码，没有业务字段改值。

题面明确要求考虑会计口径、列标题、报表年度、重述和舍入。对正常对照误报会单独记录；对证据不足的保留判断也会记录，不把它自动当作错误的篡改指控。

## 4. 实际结果

临时内容完成分 **62.92/100**，完整完成 **4/10** 题。

H01与H09漏检，H06误报。H03漏了两处重复位置，H04漏了两处Total列变化。H07虽然读到了全部7组前后数字，但把两处负号变化归到错误的资产负债表和第2页；正确位置在第1页净成本表，因此仅5/7组具有正确字段归属。这两项计入未匹配输出，不是声称模型捏造了两个全新的数字变化。H10的11处年度与单位差异则全部找对。

单套核查内容完成率为40%，双版本对比的平均内容完成率为85.84%。H09和H10都涉及billions/millions变化：前者没有参照版本时漏报单位矛盾，后者有A/B时能完整指出标签变化。这是本批观察，支持把差异检测与金融一致性核验分开报告，尚不能据此确定模型内部的失败原因。

详细核分见[evaluation.json](evaluation.json)与[逐题裁决](manual_grading.json)。原始模型回答保存在 `runs/Hxx/result.json`。核分由当前Codex对照确定性修改真值与独立数值核验完成，不是独立专家评审。

主内容分沿用基础轮思路：单套异常题需有正确判断和至少一条可验证的受影响关系；双版本题按正确前后值、页面及字段归属的目标字段召回计分。重复位置分别计数，额外误报另报，边界框不计入主分。完整口径见[grading_protocol.json](grading_protocol.json)。

与基础轮的分数比较只能用于观察本批开发题的难度变化。本轮同时改变了页数、字段数量和任务内容，样本也高度同源，不能据此给出独立的因果结论、模型总能力判断或正式榜单排名。

## 5. 数据来源、构造与核验

- [TREASURY2024官方PDF](https://fiscal.treasury.gov/system/files/files/reports-statements/financial-report/2024/financial-statements-2024.pdf)；[原始下载副本](sources/TREASURY2024.pdf)。
- [TREASURY2025官方PDF](https://fiscal.treasury.gov/system/files/2026-03/financial-statements-2025.pdf)；[原始下载副本](sources/TREASURY2025.pdf)。

选用的是官方财务报表分册中的公开财务表格，不含原先敏感材料。来源、取得时间和哈希保存在[source_manifest.json](source_manifest.json)。联邦雇员履职创作的政府作品通常在美国属于公有领域，参见[美国国会图书馆说明](https://www.loc.gov/legal/security-copyright-and-privacy/understanding-copyright/)；本实验没有选择第三方照片，也没有将整站素材一概视为相同许可。

本轮继续采用原生PDF修改后统一渲染为PNG，复用原文档字体、字号、颜色和布局，不代表真实PS或生成式修图的分布。修改版和对照版会重写相同候选位置，对照写回原值，减少插字处理本身成为答案线索的风险。

全部21个页面资产已检查文本读回和非目标文字保留；11个内容修改页进行了逐像素比较，标注范围外没有变化，允许4像素边缘余量。另用Decimal核验所列局部等式、跨页差额及单位换算。核验见[verification.json](verification.json)与[算术记录](private/arithmetic_checks.json)。这些检查验证构造范围和数值关系，不是独立真实性或逼真度认证。

## 6. 文件及复现边界

- `questions/`：每题完整图片、题面和附件映射；`schemas/`：输出格式。
- `sources/`：两份官方PDF；`assets/`：处理对照及研究修改件。
- `private/`：构造规格、前后值、页码及关系真值。仅与解题输入分离，内容全部来自本次公开构造。
- `runs/Hxx/result.json`：实际回答、用量和工具事件；不包含认证、内部日志或运行数据库。
- `prepare.py`：固定题目构造；`verify.py`：哈希、范围及冻结核验；`run_luna.py`：有界盲答；`review.py`：审阅页。

本机复用上一轮已有PyMuPDF1.26.6，没有安装新依赖。构造脚本保留原样；发布版调用器通过 `CODEX_BIN` 或PATH定位Codex，去除了机器专用路径。这一项转换及前后哈希记录在[publication_manifest.json](publication_manifest.json)，原始冻结记录保留不变，发布版核验器只允许该调用器哈希例外，不允许题面或答案哈希例外。它在当前工作区读取相邻的 `public-financial-pilot-20261104` 目录以复用公开来源清单和调用器，原实验调用本机已安装Codex，发布版改用环境变量或PATH查找。移植时需要提供对应前序目录或配置路径，再生成新的冻结记录，不能把移植后的哈希冒充本次原始记录。不要在已有运行目录中重新生成题面后混用旧回答。

目前是一个冻结的开发难度实验，尚未扩展到独立公司、中文材料、跨来源合同链或真实图像编辑。下一步应按具体失败机制做匹配对照，判断问题主要出在跨页检索、字段枚举、单位理解还是正常变更辨别。
